## How I approach engineering

- **Product first:** connect technical decisions to a clear user or business outcome.
- **Performance by design:** keep rendering boundaries, data flow and bundle cost intentional.
- **Maintainable systems:** prefer typed contracts, reusable modules and focused abstractions.
- **Confidence in delivery:** test critical behavior and automate repeatable checks.
